# Glossary

Outlet Pro uses the following terminology:

| Name            | Definition                                                |
| --------------- | --------------------------------------------------------- |
| Outlet          | Shopping destination featuring deals on overstocked items |
| Outlet page     | WordPress page for an outlet                              |
| Outlet products | Products in outlet                                        |
| Outlet badge    | Visual mark displayed on outlet products                  |
| Outlet hero     | Hero section on the outlet page                           |
| Outlet message  | Optional message shown on outlet products                 |
| Discount level  | A percentage discount range, e.g. "70% off or more".      |
| Price band      | A price range, e.g. "Under $20"                           |

👍 Use:

- “View the outlet page.”
- “The outlet product is on sale.”
- “Add the product to your outlet.”

👎 Avoid:

- The outlet

❌ Don't use:

- The store’s outlet
- Outlet section
- Mark as outlet
- Outlet membership
- Outlet status
