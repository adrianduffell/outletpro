# [Documentation](https://outletpro.zip/documentation/)

Outlet Pro allows your WooCommerce store to have a dedicated outlet page for
listing overstocked and discontinued products.

## Getting started

To set up your store with Outlet Pro, first **tag your outlet products** and then
**publish the outlet page**.

---

### Tagging outlet products

Products can be included in the store’s outlet in two ways:

- Using the product editor to include a single product
- Using bulk edit to include multiple products at a time

##### Tag a single product with the product editor

1. In **Products**, edit an existing product or create a new one.
2. Scroll to the **Product data** section.
3. Click the **Inventory** tab.
4. Check **Include in outlet**.

##### Tag multiple products in the store’s outlet with bulk edit

1. In **Products,** use the checkboxes to select each of the products to be tagged.
2. Select **Bulk Actions** → **Bulk edit** → **Apply**
3. In the **Bulk Edit** panel, change the **Outlet** dropdown to **Include**.
4. Press **Update**

---

### Publishing the outlet page

1. In **Pages**, locate the page labelled “**Outlet page**” and click to edit it.
2. If needed, change the name of the outlet by changing the page title and slug
3. The page can be modified in any way supported by the WordPress page editor –
   add images, text, or anything else needed.
4. Click **Publish** and follow the steps to publish the page.

---

### Customizing the outlet badge

Customization depends on whether the site has a **block** or **classic theme**
active.

##### Block theme

**Watch the video**:
[Finding the outlet settings on a block theme](https://outletpro.zip/finding-the-outlet-settings-on-a-block-theme/)

1. Open the site editor via **Appearance** → **Editor**
2. Choose **Templates** → **WooCommerce** and select a template the badge appears
   on, such as:

   - Page: Cart
   - Page: Checkout
   - Single Product

3. From the **3-dots** at the top-right corner, choose **Outlet settings**
4. Use the controls to change label text, colors, typography, dimensions, or
   border.
5. The settings apply the badge across the site. Switch to another template in
   step 2 to preview the change elsewhere on the site.
6. Press **Save** and follow the on-screen steps.

##### Classic theme

1. Open the customizer via **Appearance** → **Customize**
2. Choose **WooCommerce** → **Outlet**
3. Change badge label, colours and scale
4. Press **Publish**

---

### Customizing the outlet message

Like the badge, the method depends on whether the site has a **block** or
**classic theme** installed.

##### Block theme

1. Open the **Outlet settings** panel (see Customizing the badge) , and change
   the tab to **Message**.
2. Change the message text.
3. Press **Save** and follow the on-screen steps.

##### Classic theme

1. Open the customizer via **Appearance** → **Customize**
2. Choose **WooCommerce** → **Outlet**
3. Change message text
4. Press **Publish**
