Move old stock easily by adding a dedicated outlet to WooCommerce.

== Description ==

This extension adds an outlet to WooCommerce stores to help sell old stock and make way for newer and exciting products.

Includes:

* A fully-customizable outlet page
* Add individual products with a single checkbox or use the bulk edit tool
* Customizable badge and message displayed on outlet products
* Adjustable naming to suit your store (e.g. "Last chance", "Clearance", "Final sale")

= What is an outlet? =

An outlet is a dedicated area to promote the products you need to clear. It helps customers easily discover products they might want before they are gone. Products in the store’s outlet display a badge and message, allowing you to apply special policies such as no change-of-mind returns.

= How do I add products to the outlet? =

Add or edit a product, scroll to the "Product data" section, and under Inventory check "Include in outlet", then save.

= Is this the same as putting products on sale? =

No. This plugin introduces a dedicated outlet, which you can name anything you like. Use it to clear old stock and apply different policies to these products. Sales campaigns are better suited for store-wide or time-limited promotions.

= Where is the outlet on my store? =

A draft outlet page named "Outlet" is automatically created when the extension is installed. Update it as needed and publish it to make it visible on your store.

== Known issues ==

= PHP notice =

A PHP notice appears briefly in the page editor when WP_DEBUG is enabled due to a core WordPress issue. See https://core.trac.wordpress.org/ticket/62407. Workaround: disable WP_DEBUG (https://developer.wordpress.org/advanced-administration/debug/debug-wordpress/).

= Pattern inserter =

The pattern inserter displays incorrect margins due to the same issue above. Use the same workaround.
