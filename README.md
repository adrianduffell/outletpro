## Getting started

To develop Outlet Pro locally:

### Prerequisites

-   Node.js 24.x
-   Docker Desktop (if using wp-env)

```sh
npm i

## Watch for changes and rebuild assets
npm run start

# Optional dev environment using wp-env
npm run wp-env start
```
