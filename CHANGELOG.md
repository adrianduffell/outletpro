## [1.0.2] - 2026-08-04

### Fixed

- The field label was mis-aligned in the bulk editor.
- The outlet badge block’s label was reverting to the default value when empty.
- A PHP notice was displaying on the widget editor.

### Removed

- The settings sidebar no longer adds an icon to the full site editor toolbar.

## [1.0.1] - 2026-06-07

### Added

- WooCommerce declarations
  - "WC requires at least" plugin header
  - "WC tested up to" plugin header
  - HPOS compatibility

## [1.0.0] - 2026-06-07

### Added

- Initial release includes outlet page, badge, and message. Compatible with block and classic themes.
